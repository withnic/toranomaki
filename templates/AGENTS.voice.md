## 音声入力について

- ユーザーは指示を主に音声入力で出している。誤認識、同音異義語の変換ミス、言い直し、独特の語順がある前提で読む。
- セッションで最初に音声入力の指示を解釈するときは、`~/.toranomaki/voice-glossary.yaml` を開き、登録語と文脈メモを確認する。ユーザーから辞書の更新を伝えられたら読み直す。
- 文脈で誤認識を読み替えてよい。読み替えによって作業範囲が大きく変わる場合や、削除・push など戻しにくい操作につながる場合は確認する。
- 新しい誤認識を読み替えたら、同じ辞書に記録する。編集の直前に最新版を読み、同じ `term` があれば `aliases` に足す。既存の項目や設定は維持し、応答で「辞書に追加: 誤認識 → 正しい語」と伝える。
- 一般語と衝突する読み替えには `context_only: true` を付け、文脈を `note` に書く。機械的に置き換える別名は、別の言葉の一部にも一致しないか確認する。衝突のおそれがあれば例を挙げて伝える。
- 辞書に追記したら、Hex に反映するかユーザーに聞く。Toranomaki のリポジトリで `uv run toranomaki sync` で差分を確認し、ユーザーが反映を希望したら `uv run toranomaki sync --apply` を実行する。
- 一部の語の反映を断られたら、その語に `context_only: true` を付け、`note` に「反映を断られた」と書いてから、同意を得た語を反映する。あとで反映を求められたら、この理由で付けた指定を外す。
- 辞書が作業領域の外にあり、権限の制限で編集できない場合は、必要な承認を求める。承認が得られなければ、追記する内容を伝える。
